## 网页预览封面

![字花模型编辑器网页分享预览](../public/og.png)

这张横图适合 GitHub README、网页 Open Graph 分享卡和项目介绍封面。它表达编辑器的分层彩色模型能力；下面三张是实际切片与打印照片。

## Bambu Studio 四色排盘

![Bambu Studio 中排布的“我恨P人”字牌](images/bambu-studio-build-plate.jpg)

可以看到白、黄、粉、蓝四种材料对应不同模型色区。导入其他设备或 AMS 配置后仍需重新核对槽位。

## 批量打印验证

![一整盘“救火圣手”彩色字牌](images/real-print-batch.jpg)

同一个模型可以在一张打印板上复制并旋转排布。批量生产前建议先单件验证最细笔画和装饰连接强度。

## 最终实物

![“我恨P人”和“救火圣手”最终打印效果](images/finished-text-signs.jpg)

实物照片同时展示了两套配色、中文字内孔、圆角外轮廓和多层厚度。公开含公司字标的图片或模型前，应确认标识使用授权。
