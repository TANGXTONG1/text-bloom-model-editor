# 3D 打印与 Bambu Studio 指南

## 导出前

- 确保文字和装饰不是只靠极细的接触点相连。
- 自定义 SVG 尽量使用闭合、填充轮廓，避免复杂描边、自交路径和肉眼不可见的小碎片。
- 0.4 mm 喷嘴下，成品最细实体建议至少约 0.8–1.2 mm；钥匙牌受力连接处应更粗。
- A1 mini 的有效平台是 180 × 180 mm，模型宽度应预留裙边或擦拭空间。其他机器也要按实际平台核对。

## 推荐的第一次打样

以下是稳妥起点，不是强制配置：

| 设置 | 建议起点 |
| --- | --- |
| 摆放 | 平背面朝下 |
| 层高 | 0.20 mm |
| 喷嘴 | 0.4 mm |
| 墙层 | 3 |
| 顶/底壳 | 4 层或更多 |
| 填充 | 10–15% Gyroid / Grid |
| 支撑 | 常规模型通常关闭 |
| Brim | 小接触面或易翘材料时开启 |

默认模型总厚度较大，适合有明显立体层次的挂牌。做冰箱贴或轻量名牌时，可以逐层降低厚度，但每层不应低于界面允许的 0.8 mm。

## Bambu Studio 颜色与耗材映射

推荐使用网页中的“下载 Bambu 纯净 3MF”。它只包含闭合网格、分件结构和对象名，不包含颜色资源、耗材预设、机器预设或切片参数，因此不会把导出器提供的临时耗材配置带进项目。

1. 用 Bambu Studio 打开纯净版 `.3mf`。
2. 如果出现导入方式选项，保留为一个项目中的多个对象/部件。
3. 在对象列表中确认底层、阴影、顶层包边、文字和装饰均存在。
4. 按对象名中的 `slot 1–4` 和十六进制色值，把分件指定到现有 AMS 槽位或手头耗材。
5. 切片后按层预览，确认每个色区从预期高度开始。
6. 检查换色次数、冲刷量和料塔位置，避免料塔与模型碰撞。

“下载带颜色提示 3MF”使用标准 3MF Materials 扩展保存四个预览色。它没有内嵌任何 Bambu 耗材预设，但部分新版 Bambu Studio 会在颜色映射过程中追加临时自定义耗材；只有需要自动颜色提示时才建议使用。

颜色只是语义提示，不代表必须使用粉、蓝、米白、黄。你可以在网页里改调色板，也可以在切片软件里重新指定耗材。

## 打印后检查

- 轻掰装饰连接处，确认没有薄弱孤岛。
- 检查中文字内孔是否完整。
- 检查平背是否适合粘磁铁、双面胶或挂件。
- 如果侧壁看起来有多边形折线，先确认是否只在极端近距离可见；再考虑加大成品、简化 SVG 或提高采样分辨率。

## 常见问题

### Bambu Studio 显示很多三角形

3MF 的表面必须由三角网格表达，所以切片软件在选中或网格查看状态下仍可能画出三角形。旧版流程把高分辨率蒙版轮廓的几乎每一个采样点都交给 `earcut`，因此平面顶盖和底盖被不必要地切得很密。

当前流程会保留高分辨率追踪和布尔运算，等到最终生成网格时，再以成品尺寸的 **0.03 mm 最大平面轮廓误差**简化闭合环。默认示例由约 11.3 万个三角形降到约 1 万个，同时继续检查每条网格边恰好由两个三角形共享。平面上仍能看到少量三角形是格式的正常表达，不代表模型没有封闭。

### 色区被合并或颜色不对

先检查导入时是否把模型强制合并为单一对象，再核对 AMS 槽位。纯净版只提供独立色区对象，不提供自动耗材映射；请根据对象名的 `slot` 和色值手动指定。需要标准颜色资源时再改用颜色提示版。

### 导入后出现陌生耗材

请改用“下载 Bambu 纯净 3MF”。标准颜色提示版中的 `colorgroup` 会触发 Bambu Studio 自己的颜色到挤出机映射；某些版本会为匹配颜色追加临时自定义耗材。纯净版不写入这些 Materials 扩展字段。

### 自定义 SVG 建模失败

在矢量软件中执行：

1. 文字转轮廓。
2. 描边转路径。
3. 合并重叠路径。
4. 删除隐藏对象和微小碎片。
5. 用普通 SVG 重新导出。
