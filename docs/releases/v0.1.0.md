# Text Bloom v0.1.0：把公司里的梗打印出来

第一个公开版本已经可以在浏览器里完成从中文排版到彩色 3MF 的完整流程。

## 这一版有什么

- 中文文字、字号、字距与成品宽度编辑
- 星星、火苗、电脑、爱心、发散线和六种可爱图案
- 自定义 SVG / 透明 PNG
- 四色色区和三层实体厚度
- 可旋转 Three.js 真实网格预览
- 面向 Bambu Studio、不含耗材配置的纯净四色分件 3MF
- 可选的标准颜色提示 3MF
- 3D 预览与下载文件共用同一几何管线
- 0.03 mm 成品误差减面，以及圆弧、闭合网格与导出元数据回归测试
- 根路径和子路径自托管导出
- “自愿加班”AI 主视觉，以及真实网页、切片和打印效果图

## 已验证

- lint、TypeScript、生产构建全部通过
- 自动化测试覆盖两款下载示例、颜色元数据、曲线误差与闭合网格
- 默认作品的所有色区均为闭合 two-manifold 网格
- npm 全依赖安全审计为 0 个已知漏洞

## 开始使用

```bash
git clone https://github.com/TANGXTONG1/text-bloom-model-editor.git
cd text-bloom-model-editor
npm ci
npm run dev
```

示例下载：

- [`自愿加班 · Bambu 纯净四色分件 3MF`](https://github.com/TANGXTONG1/text-bloom-model-editor/raw/refs/tags/v0.1.0/examples/models/zi-yuan-jia-ban-bambu-clean.3mf)
- [`我恨P人 · Bambu 纯净四色分件 3MF`](https://github.com/TANGXTONG1/text-bloom-model-editor/raw/refs/tags/v0.1.0/examples/models/wo-hen-p-ren-bambu-clean.3mf)

示例不写入颜色资源、耗材预设或机器配置；请按对象名中的色槽提示，把分件映射到现有 AMS 耗材。首次打印还应重新核对成品尺寸。带公司 Logo 的公开模型请先确认标识授权。

完整变化见 [`CHANGELOG.md`](https://github.com/TANGXTONG1/text-bloom-model-editor/blob/main/CHANGELOG.md)。
