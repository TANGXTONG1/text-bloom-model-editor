# Text Bloom v0.1.0：把公司里的梗打印出来

![Text Bloom 最终实物](https://raw.githubusercontent.com/TANGXTONG1/text-bloom-model-editor/main/docs/images/finished-text-signs.jpg)

第一个公开版本已经可以在浏览器里完成从中文排版到彩色 3MF 的完整流程。

## 这一版有什么

- 中文文字、字号、字距与成品宽度编辑
- 星星、火苗、电脑、爱心、发散线和六种可爱图案
- 自定义 SVG / 透明 PNG
- 四色色区和三层实体厚度
- 可旋转 Three.js 真实网格预览
- 面向 Bambu Studio 的彩色闭合 3MF
- 3D 预览与下载文件共用同一几何管线
- 圆弧、闭合网格与默认模型回归测试
- 根路径和子路径自托管导出

## 已验证

- lint、TypeScript、生产构建全部通过
- 8 项自动化测试通过
- 默认作品的所有色区均为闭合 two-manifold 网格
- npm 全依赖安全审计为 0 个已知漏洞
- 已完成 Bambu Studio 排盘与真实批量打印

![Bambu Studio 四色排盘](https://raw.githubusercontent.com/TANGXTONG1/text-bloom-model-editor/main/docs/images/bambu-studio-build-plate.jpg)

## 开始使用

在线版：<http://118.145.70.247/text-model-editor/>

```bash
git clone https://github.com/TANGXTONG1/text-bloom-model-editor.git
cd text-bloom-model-editor
npm ci
npm run dev
```

首次打印请在 Bambu Studio 中重新核对成品尺寸和 AMS 槽位。带公司 Logo 的公开模型请先确认标识授权。

完整变化见 [`CHANGELOG.md`](https://github.com/TANGXTONG1/text-bloom-model-editor/blob/main/CHANGELOG.md)。
