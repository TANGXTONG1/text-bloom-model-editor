# 3D 打印与 Bambu Studio 指南

## 导出前

- 确保文字和装饰不是只靠极细的接触点相连。
- 自定义 SVG 尽量使用闭合、填充轮廓，避免复杂描边、自交路径和肉眼不可见的小碎片。
- 0.4 mm 喷嘴下，成品最细实体建议至少约 0.8–1.2 mm；钥匙牌受力连接处应更粗。
- A1 mini 的有效平台是 180 × 180 mm，模型宽度应预留裙边或擦拭空间。其他机器也要按实际平台核对。

## 推荐的第一次打样

以下是稳妥起点，不是强制配置：

| 设置 | 建议起点 |
| --- | --- |
| 摆放 | 平背面朝下 |
| 层高 | 0.20 mm |
| 喷嘴 | 0.4 mm |
| 墙层 | 3 |
| 顶/底壳 | 4 层或更多 |
| 填充 | 10–15% Gyroid / Grid |
| 支撑 | 常规模型通常关闭 |
| Brim | 小接触面或易翘材料时开启 |

默认模型总厚度较大，适合有明显立体层次的挂牌。做冰箱贴或轻量名牌时，可以逐层降低厚度，但每层不应低于界面允许的 0.8 mm。

## Bambu Studio 颜色映射

1. 用 Bambu Studio 打开下载的 `.3mf`。
2. 如果出现导入方式选项，保留为一个项目中的多个对象/部件。
3. 在对象列表中确认底层、阴影、顶层包边、文字和装饰均存在。
4. 将四个颜色资源映射到实际 AMS 槽位或手头耗材。
5. 切片后按层预览，确认每个色区从预期高度开始。
6. 检查换色次数、冲刷量和料塔位置，避免料塔与模型碰撞。

颜色名只是语义提示，不代表必须使用粉、蓝、米白、黄。你可以在网页里改调色板，也可以在切片软件里重新指定耗材。

## 打印后检查

- 轻掰装饰连接处，确认没有薄弱孤岛。
- 检查中文字内孔是否完整。
- 检查平背是否适合粘磁铁、双面胶或挂件。
- 如果侧壁看起来有多边形折线，先确认是否只在极端近距离可见；再考虑加大成品、简化 SVG 或提高采样分辨率。

## 常见问题

### Bambu Studio 显示很多三角形

3MF 的表面本来就是三角网格。关键是三角形是否形成闭合实体，以及在目标打印尺寸下轮廓是否足够平滑。网页中的 3D 视窗会隐藏平面顶盖的三角光照缝，但切片软件可能仍能在选中状态显示网格边。

### 色区被合并或颜色不对

先检查导入时是否把模型强制合并为单一对象，再核对 AMS 槽位。导出文件同时提供独立色区对象和颜色资源，但不同版本切片软件的自动映射行为可能不同。

### 自定义 SVG 建模失败

在矢量软件中执行：

1. 文字转轮廓。
2. 描边转路径。
3. 合并重叠路径。
4. 删除隐藏对象和微小碎片。
5. 用普通 SVG 重新导出。
